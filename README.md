# Petlove em React Native

Protótipo navegável das 12 telas móveis do Figma. Feito com Expo e componentes nativos.

```bash
npm install
npm start
```

Escaneie o QR code no Expo Go ou pressione `a`/`i` para abrir um simulador. Os dados e ações de compra são demonstrações locais, sem integração de pagamento ou autenticação real.

As imagens usam URLs temporárias de exportação do Figma; para distribuição, substitua os endereços de `assets.ts` por arquivos locais exportados do projeto. O arquivo também contém layouts administrativos de desktop, que não integram este aplicativo móvel.
